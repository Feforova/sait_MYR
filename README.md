# МУР

Закрытый сайт для трёх подруг: Маши, Раи и Ульяны. Пастельный, пушистый и только для своих.

При входе открывается заставка: мохнатые буквы МУР, летающие сердечки и петушки, мультяшные девочки. По кнопке «Посетить сайт» нужно выбрать себя и ввести свой пароль.

## Что внутри

| Вкладка | Что можно делать |
|---|---|
| Лента | Фото, скрины и мемы, реакции, комментарии, отметки подруг |
| Анкеты | Выбор дня («кофе или чай»), мини-опросы, анкета о себе, проценты совпадений |
| Фильмы | Обложка, описание, оценка 1–10 от того, кто советует, отметки «посмотрела» и отзывы подруг |
| Wishlist | Хотелки с фото, праздником, ценой и ссылкой. Бронирование подарка: кто первая, того и подарок |
| Спорт | Рейтинг по баллам, запись тренировок, цель и замеры с графиком, недельные отчёты, 30 упражнений с анимацией |
| Игры | Комнаты до 10 человек: «Рисуем вместе», «Кто из нас?», «Ассоциации», «Чей ответ?» |
| Планы | Доска «Идеи / На этой неделе / Когда-нибудь / Сделали» |
| Настроение | Ежедневный чек-ин цветом, неделя цветом, «температура компании» |
| Воспоминания | Лента времени с датами и фото |
| Идеи | Хотелки и мечталки с голосованием, перенос в планы |

## Файлы

```
index.html       весь сайт: разметка, стили и код
config.js        ключи базы Firebase (заполняются один раз)
firestore.rules  правила доступа к базе
README.md        эта инструкция
```

Сборка не нужна: это обычный статический сайт.

## 1. Выложить на GitHub Pages

1. Создай на GitHub новый репозиторий, например `mur`.
2. Загрузи в него все файлы из этой папки: **Add file → Upload files**.
3. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажми **Save**.
4. Через минуту-две сайт откроется по адресу вида `https://твой-логин.github.io/mur/`.

> **Важно.** Пока `config.js` пустой, сайт работает в локальном режиме: каждая девочка видит только то, что сама добавила в своём браузере. Чтобы данные стали общими, сделай шаг 2.

## 2. Подключить общую базу (Firebase, бесплатно)

1. Зайди на [console.firebase.google.com](https://console.firebase.google.com) и нажми **Создать проект**. Google Analytics можно отключить.
2. В меню слева открой **Build → Firestore Database → Create database**. Выбери ближайший регион и **production mode**.
3. На вкладке **Rules** замени текст содержимым файла `firestore.rules` и нажми **Publish**.
4. Открой **Project settings** (шестерёнка) и в разделе **Your apps** нажми значок `</>` (Web app). Придумай любое имя и нажми **Register app**.
5. Firebase покажет объект `firebaseConfig`. Скопируй значения `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId` в `config.js`.
6. Загрузи обновлённый `config.js` на GitHub (замени старый файл).

После этого все трое видят одну и ту же ленту, фильмы, вишлист, рейтинг и игры. Обновления подруг появляются сами.

Ключи из `config.js` не секретные: Firebase рассчитан на то, что они лежат в коде сайта. Доступ к данным решают правила из шага 3.

## Как устроен вход

- В первый раз каждая девочка выбирает себя и **придумывает свой пароль**. Дальше сайт спрашивает его при каждом входе.
- Сменить пароль можно в профиле: кружок с буквой справа вверху.
- Пароли хранятся в базе в виде хеша, а не открытым текстом.

## О приватности

Пароль на сайте — это замочек для своих, а не банковская защита. Любой, кто узнает адрес сайта и разбирается в коде, теоретически может прочитать базу. Поэтому:

- не выкладывай ссылку публично;
- не храни на сайте документы, адреса и другие по-настоящему секретные вещи;
- в репозитории стоит `noindex`, чтобы поисковики не показывали сайт.

Если нужна настоящая защита, следующий шаг — Firebase Authentication и правила, которые пускают только трёх конкретных людей.

## Ограничения

- Фото автоматически сжимаются примерно до 200 КБ, чтобы помещаться в базу.
- Видео добавляются ссылкой (облако, Telegram, YouTube), а не файлом.
- Игры «Стилист» и «Огонь и вода» пока в статусе «скоро».
